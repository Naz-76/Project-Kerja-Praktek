Alur sistem admin:

-Navigation bar admin sebaiknya di simpan di sisi kiri bukan di atas karena admin memiliki banyak menu yang berbeda 
-Setelah konfirmasi pendaftar diterima tidak ada fungsi untuk mengirim surat balasan & setelah status diterima jika admin menekan ditolak dan memberi pesan penolakan maka status penerimaan masih bisa di ubah.
-Buat dashboard admin menampilkan detail mahasiswa atau kelompok yang terdaftar urutkan dari paling terbaru diterima.
-Buat Menu untuk Laporan beriisikan rekap pendaftar, rekap program, rekap bidang, rekap status
-Buat Menu Profil Admin untuk mengelola profile admin
-Buat kotak pesan penerimaan tidak hanya kotak pengisian bidang
